# AssemblerVM
 Assembly machine
Virtual Machine Visual studio 2022 Language: C++ Language Version: ISO C++20 Standard (/std:c++20) 
How to: Load (Main.cpp, VM.h, syntaxChecker.h, and Assembler.h) or load the soluton from the compressed zipfile "AssemblerVMCode" into visual studio 2022 and build an executable. 
Then go to the directory where the executable is located and open that path in the terminal/Command Prompt. 
From there type out the executable name (AssemblerVM.exe) and include the .asm or .bin file name as one of the arguments and press enter. 
Code should run according to the .asm or .bin file given and output a .bin file or output to the screen.
